# KAPI — beta gratuita instalable

Presupuestos en Bs/USD, catálogo personalizable y ruedas de disponible. Cada persona guarda sus registros en su propio dispositivo. Descargá un respaldo desde Ajustes.

Instalación: abrir el enlace HTTPS en Safari (iPhone) o Chrome (Android) y añadir a pantalla de inicio.

Esta beta no conecta cuentas en nube ni IA generativa. El análisis local se identifica como cálculo. No contiene claves ni registros financieros. No requiere suscripción ni activa servicios pagos.
